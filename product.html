Our product

The SmartTrap monitoring system

A field trap, a gateway, and a dashboard that work together to count pests and track orchard conditions automatically.

How it works

  1. An insect enters the trap

    Target insects are drawn into the trap and funnel down into the detection chamber.

  2. Infrared beams detect it

    Two layers of infrared beams line the chamber. An insect breaking a beam is counted, and the second layer keeps the same insect from being counted twice.

  3. The trap logs the event

    Each detection is saved with a timestamp, along with temperature, humidity, and battery readings. An onboard memory card backs everything up.

  4. A gateway relays the data

    A shared gateway collects data from nearby traps over short-range Wi-Fi and sends it to the cloud over cellular, so the orchard doesn't need internet coverage.

  5. You see it on the dashboard

    Trap locations, counts, and conditions appear on a map, with history charts and temperature and humidity heatmaps.

How we keep costs low

  • No cameras or image processingCounting with an infrared beam needs far less power, storage, and bandwidth than photos do.
  • One cellular connection for many trapsTraps use low-power Wi-Fi to reach a shared gateway, so each trap doesn't need its own cellular plan.
  • Location set once at installA trap's position is saved when it's placed, so no GPS module drains its battery.
  • Backups at every stepTraps and the gateway both keep local copies, so a dropped connection doesn't mean lost data.
