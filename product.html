Our product

The SmartTrap monitoring system.

A field trap, a gateway, and a dashboard that count pests and track orchard conditions automatically.

How it works

From trap to dashboard, automatically.

  1. An insect enters the trap

    Target insects are drawn in and funnel down into the detection chamber.

  2. Infrared beams detect it

    Two layers of infrared beams line the chamber. Each break is counted, and the second layer prevents double counts.

  3. The trap logs the event

    Every detection is saved with a timestamp, temperature, humidity, and battery level, with a local backup.

  4. A gateway relays the data

    A shared gateway collects data from nearby traps over Wi-Fi and sends it to the cloud over cellular.

  5. You see it on the dashboard

    Trap locations, counts, and conditions on a map, with history charts and heatmaps.

The system

Three parts, one network.

In the orchard

SmartTrap field node

  • Dual-layer infrared detection
  • Temperature and humidity sensor
  • Onboard backup storage
  • Solar-charged battery

At the edge

Field gateway

  • Collects data from nearby traps
  • Cellular connection to the cloud
  • Holds data if the connection drops

On any device

Web dashboard

  • Satellite map of every trap
  • History charts per trap
  • Temperature and humidity heatmaps
  • Register traps from your phone

Cost

How we keep costs low.

No cameras or image processing

Counting with an infrared beam needs far less power, storage, and bandwidth than photos.

One cellular connection for many traps

Traps reach a shared gateway over low-power Wi-Fi, so no trap needs its own cellular plan.

Location set once at install

A trap's position is saved when it's placed, so no GPS module drains its battery.

Backups at every step

Traps and the gateway both keep local copies, so a dropped connection doesn't lose data.

FAQ

Frequently asked questions

How does SmartTrap detect insects?

Insects entering the trap pass through two layers of infrared beams. Each beam break is logged as a detection with a timestamp, and the second layer keeps the same insect from being counted twice.

Does my orchard need Wi-Fi or internet?

No. Traps connect to a nearby SmartTrap gateway over short-range Wi-Fi, and the gateway sends data to the cloud over cellular. The gateway just needs cell coverage.
