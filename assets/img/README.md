# Website images

Pages look for these files. Until a file exists, its spot shows a striped placeholder labeled with the file name. Photos are cropped to fill their box, so any size works, but landscape shots of at least 2000px wide look best for the heroes.

| File | Used on |
|---|---|
| `hero-orchard.jpg` | Home page hero (full screen, behind white text, so darker photos work best) |
| `product-hero.jpg` | Our Product page hero |
| `trap-field.jpg` | SmartTrap installed in an orchard (home page, product page) |
| `gateway.jpg` | Field gateway (product page) |
| `dashboard.png` | Dashboard screenshot (home page, product page) |
| `team.jpg` | Team photo (About Us page) |
| `footer-orchard.jpg` | Photo in the footer contact card (every page) |

Keep each photo under about 500 KB (export as JPG at ~80% quality) so pages load quickly.
